## Brand & Style

The design system is a high-performance framework engineered for professional environments that demand both technical precision and aesthetic velocity. It targets developers, data scientists, and engineers who appreciate the intersection of F1-grade aerodynamics and AI research aesthetics. 

The design style is **Cyberpunk Minimalism**. It utilizes a deep charcoal foundation to provide a high-contrast stage for energetic accents. The interface leans heavily into **Glassmorphism** for telemetry overlays and **Kinetic Interactivity**—incorporating 2-degree skews, motion-sensitive hover states, and structural grid lines that simulate a heads-up display (HUD). The emotional response is "Technical Sophistication"—sophisticated, aggressive, yet mathematically ordered.

## Colors

The palette is strictly optimized for dark-mode performance. The core experience is built on **Carbon Black (#121414)**, which serves as the low-reflectivity surface for all data visualization.

- **Primary (Norris Yellow):** High-visibility accent color used for critical telemetry, active states, and call-to-action triggers.
- **Secondary (Neutral White):** Used primarily for high-contrast typography and icon labels.
- **Tertiary (Surface Bright):** Employed for structural division and subtle container differentiation.
- **Telemetry Accents:** A specialized set of translucent values (20% opacity primary) used for grid overlays, crosshairs, and kinetic decorative lines to simulate a real-time tracking environment.

## Typography

The typography system mirrors a "Driver-as-Engineer" persona, mixing geometric impact with technical utility.

- **Display & Headlines:** Use **Outfit** in heavy weights. Large display elements should feature a `-2deg` skew (italic-like but structural) to suggest forward motion and velocity.
- **Technical Layers:** Use **JetBrains Mono** for all metadata, labels, and code. This font should always be used for "Status" indicators and data readouts.
- **Body Content:** **Inter** provides the necessary neutral foundation for long-form documentation, ensuring high legibility against the dark background.
- **Mobile Scaling:** Headlines scale aggressively for mobile devices to maintain impact without overwhelming the smaller viewport.

## Layout & Spacing

The layout utilizes an **Asymmetric Modular Grid** that favors staggered, rhythmic compositions over symmetry. 

- **Grid Model:** A 12-column fluid grid. Elements should be encouraged to span irregular column counts (e.g., 5-column primary with a 3-column sidebar) to create a "dashboard" look.
- **Staggered Scroll:** Implement variable top margins for modular components. As the user scrolls, the content should feel like it is unfolding at different speeds, reinforcing the "kinetic" nature.
- **Breakpoints:**
  - **Desktop (1440px+):** 64px margins, asymmetric layout.
  - **Tablet (768px - 1439px):** 32px margins, 8-column grid.
  - **Mobile (<768px):** 20px margins, single-column vertical stack with minimal skewing to preserve readability.

## Elevation & Depth

Depth is achieved through **Glassmorphism** and **Tonal Tiering**, emphasizing transparency over shadows.

- **Base Layer:** The deepest Carbon Black (#121414).
- **Surface Layer:** Secondary containers use a slightly lighter grey with a 1px solid border at 10% opacity white.
- **Glass Overlay:** High-interactivity panels (like nav bars or quick-info modals) use a `backdrop-filter: blur(16px)` with a semi-transparent dark fill (`rgba(18, 20, 20, 0.7)`).
- **HUD Lines:** Use 0.5px "hazard lines" (Norris Yellow at 20% opacity) to frame glassmorphic elements, creating the illusion of a projected technical interface.
- **Interactivity:** On hover, elements should use a "Kinetic Shift"—a subtle 2px translation or a "glitch" transition rather than a standard fade.

## Shapes

The system uses a **Soft-Technical** shape language. 

- **Corner Radius:** A default **0.25rem (4px)** radius is applied to maintain a sharp, precise aesthetic.
- **Chamfered Accents:** For large race-hub modules or featured cards, utilize a single **45-degree clipped corner** (top-right) to mimic automotive chassis engineering.
- **Interactive Elements:** Buttons and data chips must remain rectangular. Avoid pill shapes or high roundedness, as they contradict the brutalist-technical narrative.

## Components

- **Action Buttons:** Primary buttons are solid Norris Yellow (#DFFF00) with black text. Hover states trigger a `skew(-2deg)` transformation and a sharp 2px "ghosting" offset.
- **Glassmorphic Cards:** Feature a blurred background, a 1px white border at 10% opacity, and a technical header in JetBrains Mono (e.g., `[ 01_TELEMETRY ]`).
- **Data Chips:** Outlined tags (1px border, no fill) used for technical categories. Text is always uppercase JetBrains Mono.
- **Telemetry Inputs:** Minimalist fields with only a bottom border. Focus states trigger a soft Norris Yellow glow and an animated progress-line appearing on the bottom border.
- **Status Indicators:** Small, blinking nodes or thin horizontal bars that resemble live telemetry charts.
- **Timeline Component:** A vertical system using thin technical lines and Norris Yellow nodes to connect milestones, looking like a "lap breakdown" chart.
